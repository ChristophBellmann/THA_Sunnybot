# Project Attribution

Sunnybot / “Die Motte” was created as a team project in the Systems Engineering program at Hochschule Augsburg.

## Team contributions

- robot construction and manufacturing
- drive-control concept and programming
- network setup and transfer of control information
- motion control based on solar-cell data

### Christoph Bellmann
- Git environment and repository organization
- software-component structure

### Felix Schirmer

- development of image-processing algorithms
- energy analysis

## Portfolio context

This GitBook is maintained as part of Christoph Bellmann’s technical portfolio and documents his participation and integration work within the team project.

The team origin and division of contributions are retained explicitly so that the project is not represented as a solely authored commercial development.
