# Development & Outlook

Sunnybot was intentionally designed as an extensible prototype.

Potential extensions identified during the project include:

- charging the batteries from the onboard solar cells,
- live energy accounting,
- behavior influenced by energy reserve,
- more expressive user interaction,
- a “help” state when energy becomes scarce,
- improved autonomy and environmental awareness,
- collision avoidance.

The original large-area scenario imagines the robot following sunlight during the day and orienting toward an artificial “home base” light source at night.

The prototype did not include collision avoidance, so autonomous operation in uncontrolled environments was not considered safe without supervision.

The strongest value of the project is the integration experience: mechanics, embedded systems, networking, perception and application software all have to cooperate for one observable behavior.
