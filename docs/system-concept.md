# System Concept

The second-semester Systems Engineering assignment was to create a “useless machine”: a system that causes a seemingly pointless state change and tends to restore its own preferred state.

Team Sunnybot interpreted this as a mobile robot that wants to remain in sufficient light.

## Requirements

The university assignment included autonomous deactivation, a user interface communicating the machine’s “emotional” state, user interaction, an energy analysis and a limited project budget.

The team added its own engineering goals:

- autonomous movement toward the strongest light source,
- networked information exchange between system components,
- modular construction with room for later extensions.

This produced a useful Systems Engineering exercise despite the deliberately playful application.
